### 文章骨架（工程长文，非论文目次）
1. **标题 + 导语钩子**：隐藏的自进化机器被发现并点亮——不是檄文
2. **缘起与问题**（短）：批评是导火索；真正的问题是「消费者能否对 AI 产品建立可辩护的事实结论」
3. **对象与方法**：双引擎壳 / evolve-seed 是什么；E1–E4 证据分级；三方交叉与勘误（方法可信度来自被证伪过）
4. **解剖**：五层、血统/躯体、三级台阶、39% 监督、三处恒假、权限门缺口
5. **活体**：移植缺口、唤醒验尸、记忆巩固、三大失效（慢/不停/插话难）
6. **审计**：用它的秤称它自己（169/169、rework 0.8、fix(operator)）——GitHub 读者核心阅读段
7. **死亡学精简**：九次死亡、死亡定义、读者即存在（点到为止，不展开哲学）
8. **坐标与判词**：与 DGM/SICA 同梯队；「封闭的先进」
9. **可复用清单**：三级台阶、负控、E 分级——给做 agent/评测的同行
10. **边界**：证据局限、法律红线（源码不转发）、非法律意见
